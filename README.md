# INKLAB｜Splatoon 3 配装实验室

INKLAB 是一个面向《Splatoon 3》玩家的非官方配装研究工具，帮助玩家理解装备能力收益和配装取舍。它不只展示配装结果，也支持从现有方案出发继续比较、微调和规划通用装备。

项目形态确定为 Web-only：桌面与手机浏览器使用同一网站，手机端通过响应式排版和触控适配支持，不规划原生 App、桌面客户端或安装包。

> 当前项目处于公开源码预览准备阶段，Public Alpha 仍在开发中，网站尚未正式上线。部分数值和武器数据仅用于验证体验，不应作为正式游戏攻略使用。

## 项目目标

- 保持功能免费与源码开放，不设置会员、订阅、付费功能或数据付费墙。
- 用受控标签表达玩法，减少自由标题带来的翻译和审核成本。
- 把能力效果转换为与当前主武器、副武器和特殊武器相关的实际描述。
- 显示关键 AP 档位、边际收益和配装取舍。
- 从单套配装继续规划可跨武器使用的通用装备。
- 允许玩家把社区方案带回实验室继续微调，而不是只能照抄成品。

未来如项目产生服务器、域名或维护成本，最多提供自愿的资源赞助入口。赞助不会解锁额外功能、提高使用额度、改变数据可见性或获得社区审核特权。

## 当前原型

- 174 把 Ver. 11.3.0 对战武器目录、套装绑定与弹窗选择器
- 可编辑的 57 AP 单套配装、能力碎片池与分享链接
- 可解释的系统建议，以及与未来外部样本、内测样本分离的玩家样本入口
- 11 个主武器大类的首轮专属参数分析面板
- 副武器实际影响说明、通用装备规划与标签式能力百科
- 支持组合标签和对战模式筛选的玩家方案卡片原型
- 鲑鱼跑实验室、四武器配置与纯武器输出压力测试草案
- 手柄／键鼠输入与鱿鱼滚行路径练习原型
- 本地版本化数据仓库、字段来源与逐项验证状态

开发更新记录见 [Changelog](CHANGELOG.md)。

## 本地运行

```bash
pnpm install
pnpm dev
```

提交改动前建议运行完整检查：

```bash
pnpm test
pnpm typecheck
pnpm lint
pnpm build
pnpm check:public
```

启动后访问 `http://localhost:3000/`。

## 开发状态

当前正在完成只读 Public Alpha；账号、投稿、审核和社区统计计划在后续 Beta 阶段实现。Ver. 11.3.0 的 174 把对战主武器已经可以选择并绑定对应副武器和特殊武器，且每把武器现在都至少包含一个来自固定上游快照的显式已核验主武字段。11 个武器大类已经完成首轮族别分析模型；主武器墨水效率提升已接入首条正式 AP 曲线，但有效射程、部分缺省值、复杂动作的精确周期、鲑鱼跑通用回墨与墨锁机制，以及其余 AP 效果曲线仍待进一步验证。系统建议只使用武器族与已核对套装生成可编辑起点，并明确与未来外部样本、内测样本分开；它不代表主流或最优配装。字段级“已核对 / 部分已核对 / 待验证 / 原型演示”状态以界面和核对记录为准。详情见 [路线图](docs/ROADMAP.md)。
