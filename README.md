# INKLAB｜Splatoon 3 配装实验室

INKLAB 是一个面向《Splatoon 3》玩家的非官方配装研究工具。它不只展示配装结果，还希望帮助玩家理解能力点数的实际变化，并以现有方案为起点继续比较、微调和规划通用装备。

> 当前项目处于本地交互原型阶段，尚未正式上线。部分数值和武器数据仅用于验证体验，不应作为正式游戏攻略使用。

## 项目目标

- 用受控标签表达玩法，减少自由标题带来的翻译和审核成本。
- 把能力效果转换为与当前主武器、副武器和特殊武器相关的实际描述。
- 显示关键 AP 档位、边际收益和配装取舍。
- 从单套配装继续规划可跨武器使用的通用装备。
- 允许玩家把社区方案带回实验室继续微调，而不是只能照抄成品。

## 当前原型

- 单套配装分析与快速配装方向
- 26 种装备能力池
- 副武器实际影响说明样板
- 通用装备规划
- 标签式能力百科
- 玩家方案卡片样板
- 手柄／键鼠输入与鱿鱼滚行路径练习原型
- 本地版本化武器数据仓库与字段验证状态

开发更新记录见 [Changelog](CHANGELOG.md)。

## 本地运行

```bash
pnpm install
pnpm dev
```

启动后访问 `http://localhost:3000/`。
