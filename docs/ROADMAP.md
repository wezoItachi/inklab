# INKLAB 路线图

本路线图说明产品方向，不代表固定发布日期。

## Prototype｜当前阶段

- [x] 单套配装分析布局
- [x] 快速配装与通用装备规划概念
- [x] 标签式能力百科和玩家方案卡片样板
- [x] 本地能力图标与来源记录
- [x] 操作实验独立页面原型
- [ ] 全武器选择
- [ ] 正式参数数据层
- [ ] 完整交互状态与错误提示

## Public Alpha｜只读公开版

- [ ] Ver. 11.3.0 武器数据快照
- [ ] 可分享的配装网址与浏览器本地保存
- [ ] 玩家方案示例库及一键微调
- [ ] 手机端、键盘和手柄操作检查
- [ ] 数据来源、版权、隐私和免责声明页面
- [ ] 基础运行监控

## Community Beta｜账号与投稿

- [ ] 网站账号与身份验证
- [ ] 标签式投稿、作者短备注及可选装备参考
- [ ] 草稿、审核、公开、隐藏和举报状态
- [ ] 限流、反机器人保护、数据导出与账号删除

## Community Research｜社区总结

- [ ] 按武器、版本和玩法标签聚合投稿
- [ ] 常见能力采用率和 AP 分布
- [ ] 系统建议、社区常见和作者经验分层
- [ ] 人工确认后更新快速配装模板

## 暂不计划

- 实时对战数据采集
- 游戏账号库存的非官方自动读取
- 未经审核的公开评论区
- 付费解锁游戏数据或官方素材
