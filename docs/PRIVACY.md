# 隐私说明（Public Alpha 草案）

更新日期：2026-10-08

## 当前版本保存什么

INKLAB 当前没有账号、服务端投稿、评论、支付或社区统计。配装编辑状态保存在你的浏览器本地存储中；清除站点数据会移除这些本地记录。

复制分享链接时，所选武器和配装槽位会编码在网址查询参数中。把链接发给他人、保存在浏览器历史或提交给其他服务时，接收方可能看到这些参数。当前分享内容不包含作者账号或自由文本备注。

本地生成的配装 PNG 在浏览器中完成并由用户主动下载，INKLAB 当前不把图片上传到服务器。

## 外部请求

鲑鱼跑实验室会由浏览器直接请求 `splatoon3.ink/data/schedules.json`，用于显示当期地图和四把武器名称。该站点及网络服务商可能按其自身规则收到常规网络请求信息，例如 IP 地址、浏览器标识和访问时间；INKLAB 不会在该请求中主动附加账号或配装内容。

页面中的 GitHub、Leanny、Sendou 素材来源和 splatoon3.ink 链接只有在用户点击时才会打开相应第三方网站，第三方隐私政策随后适用。

## 当前没有的行为

- 没有广告、行为分析、跨站追踪或个性化推荐脚本。
- 没有服务器端保存的玩家方案或个人资料。
- 没有出售或交换用户数据。

若未来加入账号、投稿、分析监控或赞助服务，必须在启用前更新本说明，列明数据字段、用途、保存期限、删除方式和第三方处理者。
