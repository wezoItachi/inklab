# 基础运行监控

INKLAB 的只读 Public Alpha 提供 `GET /api/health` 健康检查端点。它用于确认 Web 服务能够响应，并返回当前公开数据快照版本。

```json
{
  "status": "ok",
  "service": "inklab",
  "schemaVersion": 1,
  "gameData": {
    "version": "12.0.0",
    "updatedAt": "2026-11-22"
  }
}
```

此端点不读取 Cookie、配装、本地存储、IP 地址或用户标识，也不在应用层保存访问记录。托管平台自身可能产生基础请求日志；正式部署前需要按实际平台补充保存期限和访问权限说明。

## 当前自动检查

- 每次提交和合并请求都会运行测试、类型检查、代码规范、正式构建、生产依赖审计、公开文件扫描和脚本体积预算。
- CodeQL 在提交、合并请求和每周计划任务中检查 JavaScript / TypeScript 安全问题。
- 健康检查响应由自动测试固定，避免把内部路径、环境变量或动态用户信息加入公开响应。

## 正式网址建立后

外部在线率探测必须等待正式部署网址确定后再启用。届时只检查 `/api/health` 的 HTTP 状态、响应时间和公开版本字段；告警接收人、探测频率、日志保存期限与服务提供方需要另行记录。没有正式网址前，不把本地开发服务器或 GitHub Actions 误称为线上可用性监控。
