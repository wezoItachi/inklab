# INKLAB 平台范围

## 当前决定

INKLAB 的产品形态确定为 Web-only。桌面和手机用户访问同一个网站；手机支持属于响应式排版、触控目标和移动浏览器兼容，不是独立移动客户端。

所有核心计算继续放在与界面无关的 TypeScript 模块中，浏览器界面只负责输入、展示和本地交互。这种解耦用于测试、维护和复用，不表示保留客户端计划。

## 支持范围

- 桌面浏览器完整功能。
- 手机浏览器响应式布局与触控操作。
- 浏览器公开的键盘、指针与 Gamepad API。
- 浏览器本地存储、分享链接和本机文件导出。

## 明确不做

- 原生移动 App。
- Electron、Tauri 或其他桌面外壳。
- PC 安装包、独立自动更新器或应用商店版本。
- PWA 安装形态；若未来重新考虑，必须作为新的产品决策，而不是默认路线。
- 系统级游戏输入读取、Nintendo Switch 连接或游戏画面读取。
