# INKLAB 平台范围

## 当前决定

Public Alpha 只实现 Web 端。所有核心计算放在与界面无关的 TypeScript 模块中，浏览器界面只负责输入、展示和本地交互。

当前不制作原生应用、Electron/Tauri 外壳、安装包、自动更新器或系统级输入读取。操作实验仍只使用浏览器公开的键盘、指针与 Gamepad API，不连接 Nintendo Switch，也不读取游戏画面。

## 保留的后续方向

核心计算层不依赖浏览器 API，因此以后可以在三种形态间选择：

1. 继续做响应式网站，并按需增加 PWA 安装能力。
2. 用 Tauri 等轻量外壳封装为 PC 工具，共用现有 Web 界面与计算层。
3. 只有在确实需要系统级能力时再开发原生应用。

是否进入 PC 工具阶段，应以离线使用、窗口置顶、文件导入导出、手柄支持或系统集成等明确需求为依据，而不是仅为了拥有安装包。
