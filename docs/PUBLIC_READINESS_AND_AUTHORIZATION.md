Sendouc 已对当时明确询问的 26 个图标范围表示可以：复制进 INKLAB 的公开 GitHub 仓库并由网站自行托管，且无需向 Sendouc 署名；其同时说明文件实际来自 `Leanny/splat3`。项目已保留取得来源、回复链接和 Nintendo 权利边界。

当前只在浏览器读取 `splatoon3.ink` 的公开日程端点中的地图与武器名称，并链接回原页面查看地图详情和更换时间；没有复制或托管其地图、武器图片。上游项目为 MIT，但正式公开前仍需保留来源说明并复核接口使用方式和可用性。

2. 允许使用 8 把熊先生印章武器的 `_Coop` 参数，并公开保存相同类型的规范化字段和来源路径。
3. 若仓库中存在玩家通用的墨水槽、潜墨回墨、动作时间等参数，允许提取用于持续 DPS 循环；需确认这些字段所在目录和继承关系。
4. 若仓库中存在鲑鱼、大鲑鱼、特殊事件或 WAVE 数据，允许提取敌人／部位生命值、装甲、眩晕阈值、出怪间隔、危险度缩放和事件时序。当前 14 个生命值目标仍是待复核社区参考值，不应冒充已获授权的 Lean 数据。

## 不应向 Lean 混在同一请求中的事项

- INKLAB 自有代码、界面、公式表达、测试、文档和系统建议规则由项目自行决定，不需要 Lean 授权。
- 玩家自行提交的配装属于社区投稿治理问题，需要投稿条款、隐私说明、删除机制和展示许可，而不是 Lean 授权。
- 从 Sendou 收集或调用玩家配装样本，需要单独核对 Sendou API／使用条款或向其维护者询问；不能用 Lean 的数据许可代替。
- 从 Bilibili Wiki 等页面参考中文名称，不等于可以复制其文章、整理成果或图片。中文名称应尽量以游戏内文本／可追溯语言数据为准。
- Discord、GitHub、赞助平台的品牌图标和链接应遵守各自品牌规则，与 Lean 无关。
- Nintendo 对游戏名称、商标与官方视觉素材的底层权利不能由 Lean 或 Sendouc 代为完全解决；项目需要继续保持非官方说明、来源记录和可替换／移除素材的结构。
- 当前只参考 Sendou 的公开交互，没有复制其代码。即使双方都采用 AGPL，日后若要复用其代码，仍必须保留原作者版权与许可说明、核对版本兼容性并记录实际来源。

## 在追加授权之前暂不做

- 不复制新的主武器、副武器、特殊武器、熊武、敌人或地图图片。
- 不批量镜像 Leanny 的完整数据目录，只保存产品实际需要的规范化字段、来源路径和哈希。
- 不抓取或导入 Sendou 玩家配装样本，不把演示方案标为社区主流。
- 不把社区参考的敌人生命值标成 Lean 数据或“官方已验证”。
- 不公开仓库、不部署网站、不联系第三方，直到用户单独确认相应步骤。

## 接近公开时的最低检查门槛

1. 所有展示数值都有版本、字段来源和“已核对／待验证／模型假设”状态。
2. 未获新增授权的视觉位置全部保持自有占位图形或纯文字。
3. 第三方数据与素材明确排除在项目 `AGPL-3.0-only` 代码许可范围外。
4. 依赖许可证、漏洞、Git 历史、本机路径、GitHub Actions 日志和敏感信息重新检查。
5. README、免责声明、隐私与社区投稿条款完成审阅。
6. 自动测试、类型检查、lint、生产构建、移动端和跨浏览器关键流程通过。
7. 仓库公开、push 和网站部署分别取得用户明确授权。
