# 鲑鱼跑纯动作压力模型（Ver. 12.0.0）

- 游戏版本：Ver. 12.0.0
- 本轮核对日期：2026-11-25
- 状态：动作窗口实验，不作持续输出或通关结论
- 参数来源：[Leanny/splat3](https://github.com/Leanny/splat3) 固定提交 `b669d55e0eef1f1a7f18cb7468c636ed7746c189`（**Data provided by Lean**）

## 当前覆盖

71 把打工武器均已有来源可追溯的部分参数，其中 14 把已经建立“理论极限／日常动作基准”两条可复算动作线：

- 10 把具备显式单发伤害、射击间隔与单发耗墨的连续射击枪；
- 三发猎鱼弓的一段蓄力极限与一段／满蓄力混合基准；
- 开尔文525、灭熄FF、熊先生印章机动枪的普通射击与翻滚后射击状态。

连续射击枪的两条动作线相同，因为当前没有用虚构命中率或统一折扣制造“普通玩家平均”。三发猎鱼弓使用明确列出的动作组合。三把双枪则把普通射击作为日常基准，把已进入翻滚后状态的连续射击作为理论极限。

## 双枪状态边界

开尔文525、灭熄FF与熊先生印章机动枪同时具备显式的普通／翻滚后伤害与射击间隔，因此可以分别复算动作 DPS。理论极限只表示“已经进入翻滚后射击状态时”的稳定射击窗口：

| 武器 | 普通状态 | 翻滚后状态 |
| --- | ---: | ---: |
| 开尔文525 | 45 伤害／9 帧，300 DPS | 70 伤害／9 帧，约 466.7 DPS |
| 灭熄FF | 40 伤害／8 帧，300 DPS | 40 伤害／4 帧，600 DPS |
| 熊先生印章机动枪 | 35 伤害／5 帧，420 DPS | 35 伤害／4 帧，525 DPS |

上述翻滚后动作线不计首次翻滚的耗墨、移动帧、硬直、重新进入状态的间隔或站位代价，因此不能直接视为整局平均输出。其他双枪虽然存在部分翻滚字段，但缺少显式翻滚后伤害时继续保持未开放，不从普通伤害自动继承。

## 自由目标实验

目标实验只计算 `目标 HP ÷ 每动作伤害`、向上取整后的实际动作数、总伤害、溢出伤害、动作帧与耗墨。它不计装甲、无敌阶段、射程、命中率、贯通、多目标、走位或机制弱点，因此只回答“按当前动作覆盖这段生命值需要几次”，不等于实际击杀速度。

## 尚未启用持续输出

普通无能力回墨字段、打工三角雷 70% 耗墨／60 帧墨锁与部分武器射后墨锁已有独立证据记录，但以下边界仍未闭环：

- 普通回墨曲线在鲑鱼跑中的适用性；
- 上游省略的射后墨锁缺省值；
- 鱿鱼滚行空中回墨及其是否绕过副武墨锁；
- 翻滚、蓄力、滚压、刀身、多弹丸等复杂动作的完整循环；
- WAVE、危险度、出怪速率、地图与潮位。

因此同步开火／同步回墨和交替开火／交替回墨仍保持禁用，不输出持续 DPS、压力过线或通关判断。旧的 Ver. 11.3.0 草案继续作为历史记录保留，不参与当前页面计算。
