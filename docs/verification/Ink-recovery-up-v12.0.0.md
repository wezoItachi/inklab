# 提升墨汁回复力曲线核验（Ver. 12.0.0）

## 固定来源

- Leanny `splat3` 固定提交：`b669d55e0eef1f1a7f18cb7468c636ed7746c189`
- 参数文件：`data/parameter/1200/misc/params.json`
- Sendou.ink 交叉核对提交：`5724392238bc47cc05ac849128a697e8c1b62a62`
- 实现文件：`app/features/build-analyzer/core/utils.ts`、`core/stats.ts` 与 `data/ability-values.ts`

Sendou.ink 仅用于交叉核对公开分析器的插值、向上取整和墨水槽换算行为，不把社区实现称为 Nintendo 官方说明。

## 两条来源曲线

| 玩家状态 | High（57AP） | Mid | Low（0AP） | 0AP 回满 | 57AP 回满 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 非潜墨 | 220 帧 | 410 帧 | 600 帧 | 10.00 秒 | 3.67 秒 |
| 潜墨 | 117 帧 | 148.5 帧 | 180 帧 | 3.00 秒 | 1.95 秒 |

网站沿用共享 AP 强度：

`p = min(3.3 × AP − 0.027 × AP², 100) / 100`

再按 `[High, Mid, Low]` 三点值插值。最终显示帧数先乘当前武器的墨水槽倍率再向上取整，秒数按 60 帧制换算。实现会在取整前消除浮点运算产生的小于 `1e-9` 的整数尾差，避免 `180 × 1.1` 被误取整为 199 帧。

## 墨水槽容量

- 通常武器：100%。
- 新叶射击枪与枫叶射击枪（上游 ID 10、11）：110%。
- 页面展示的是从空槽回满当前整槽所需时间，因此 110% 墨水槽的完整回满时间是普通墨水槽的 1.1 倍。

## 产品口径

- 能力百科以潜墨状态曲线为主轴，同时明确存在非潜墨曲线。
- 实验室同时显示两种状态的回满帧数、秒数与相对 0AP 的节省量。
- `3AP` 只表示首个可装备且会改变公式结果的投入，不是强制配装建议。
- 这里计算纯恢复阶段，不包含主武器或副武器动作后的 `InkRecoverStop`（社区常称“墨锁”）。
- 这套曲线当前只标记为普通对战已核对。Ver. 12.0.0 数据中仍未找到明确的鲑鱼跑玩家通用覆盖字段，因此不会把普通对战曲线直接代入鲑鱼跑持续 DPS。
