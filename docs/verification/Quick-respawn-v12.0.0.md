# 缩短复活时间核验（Ver. 12.0.0）

## 结论

“缩短复活时间”只在玩家上次复活后没有击倒对手、随后被击倒时生效。实验室已接入标准条件复活曲线，并独立显示自身或对手装备复活惩罚时的边界，不把它描述成每次死亡都会生效。

## 固定来源

- 游戏版本：Splatoon 3 Ver. 12.0.0
- Leanny 参数提交：`b669d55e0eef1f1a7f18cb7468c636ed7746c189`
- 两段复活三点值：`data/parameter/1200/misc/params.json#Dying_ChaseFrm,Dying_AroundFrm`
- 交叉核对：Sendou.ink 构建分析器固定实现

标准条件复活时间由固定阶段与两条 AP 曲线组成，0AP 为 450 帧（7.50 秒），57AP 为 210 帧（3.50 秒）。`3AP` 是首个可装备且会改变公式结果的投入。

自身装备复活惩罚会增加 68 帧；被装备复活惩罚的对手击倒时会增加 45 帧，并将快活 AP 压缩到原投入的 15% 后向上取整。能量站增益可以改变对手复活惩罚压制 AP 的边界，但当前页面没有对局内饮料状态，因此不假设增益已生效。

## 当前不包含

- 没有满足快活触发条件的普通死亡；
- 能量站饮料的实时获取与持续时间；
- 落地、重生动画结束后恢复操作的主观延迟；
- 网络与画面显示造成的计时差异。
