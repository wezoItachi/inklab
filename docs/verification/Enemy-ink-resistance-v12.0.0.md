# 减轻对手墨汁影响核验（Ver. 12.0.0）

## 结论

实验室已把“减轻对手墨汁影响”拆成四条正式曲线：敌墨中的普通移动速度、开始受到敌墨伤害前的缓冲帧、敌墨持续伤害与敌墨自身可累积的伤害上限。页面不把四种不同单位压缩为一个“抗性百分比”。

## 固定来源

- 游戏版本：Splatoon 3 Ver. 12.0.0
- Leanny 参数提交：`b669d55e0eef1f1a7f18cb7468c636ed7746c189`
- 三点值：`data/parameter/1200/misc/params.json`
- 交叉核对：Sendou.ink 构建分析器固定实现

| 效果 | 0AP | 57AP |
| --- | ---: | ---: |
| 敌墨普通走速 | 0.240 | 0.768 单位/帧 |
| 开始受伤前缓冲 | 0 | 39 帧 |
| 敌墨持续伤害 | 18 | 9 /秒 |
| 敌墨累计伤害上限 | 40 | 20 |

中间 AP 使用项目共享的游戏效果强度和三点插值协议。`3AP` 是首个可装备且会同时改变四项原始结果的投入，因此作为本站“最小有效值”，不代表所有配装必须投入。

## 当前不包含

- 武器射击动作中的敌墨移动速度；
- 敌墨中的跳跃速度；
- 与主武器、副武器或特殊武器伤害同时发生时的实战存活时间；
- 伤害恢复、脱离敌墨与再次踩入敌墨组成的完整时间序列。

这些内容不能由四条静态端点直接推算。
