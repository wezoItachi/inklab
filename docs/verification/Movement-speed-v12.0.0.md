# 游速与普通走速核验（Ver. 12.0.0）

## 结论

实验室已接入“提升鱿鱼冲刺速度”和“提升人类移动速度”的正式 AP 曲线，并按当前主武器的轻量／中量／重量级选择对应三点值。能力百科使用中量级作为统一展示基准，避免把某一把武器的基础速度冒充通用值。

## 固定来源

- 游戏版本：Splatoon 3 Ver. 12.0.0
- Leanny 参数提交：`b669d55e0eef1f1a7f18cb7468c636ed7746c189`
- 通用能力三点值：`data/parameter/1200/misc/params.json`
- 武器重量级：各武器参数文件的 `GameParameters.MainWeaponSetting.WeaponSpeedType`
- 交叉核对：Sendou.ink 构建分析器固定实现

174 套武器记录由 `scripts/import-leanny-movement-classes.mjs` 生成。上游显式值只出现为 `Fast`、`Mid` 或 `Slow`；字段未覆盖时按标准 `Mid` 处理，并在记录中标为 `standard-default`，不伪装成上游显式字段。当前目录计数为轻量 39、中量 118、重量 17（套装变体分别计数）。

## 三套端点

页面沿用公开分析器的“游戏单位/帧”口径，将参数值乘以 10：

| 状态 | 重量级 | 0AP | 57AP |
| --- | --- | ---: | ---: |
| 潜墨移动 | 轻量 | 2.016 | 2.400 |
| 潜墨移动 | 中量 | 1.920 | 2.400 |
| 潜墨移动 | 重量 | 1.728 | 2.400 |
| 普通人形态移动 | 轻量 | 1.040 | 1.440 |
| 普通人形态移动 | 中量 | 0.960 | 1.440 |
| 普通人形态移动 | 重量 | 0.880 | 1.440 |

中间 AP 使用项目共享的游戏效果强度和三点插值协议。`3AP` 是第一个可装备且会改变三种重量级原始结果的投入，因此作为本站“最小有效值”；它不是配装强制建议。

## 鱿鱼忍者

鱿鱼忍者是服装限定主能力，不属于可重复堆叠的 AP 曲线。实验室先计算当前游速 AP，再独立应用 `0.9` 倍固定修正，并同时显示修正前结果。走速不应用这项修正。

## 当前不包含

- 射击、蓄力、满蓄力或第二射击模式下的武器专用走速；
- 持有真格鱼虎时的移动惩罚；
- 敌方墨汁中的走速、跳跃与伤害；
- 鲑鱼跑是否使用完全相同的玩家移动参数。

这些状态必须分别核验对应基础速度、倍率、覆盖字段和生效条件，不能由普通人形态曲线直接推导。
