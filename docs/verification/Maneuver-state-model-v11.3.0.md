# 双枪普通／翻滚后状态模型（Ver. 11.3.0）

核对日期：2026-10-10

## 本轮结论

双枪不能沿用普通射击枪的单一射击状态。INKLAB 现将普通射击和翻滚后定点射击拆成两套窗口，分别读取普通／翻滚后的伤害、射击间隔与扩散角。

固定参数快照显示：

- 开尔文525系显式提供 `DamageLapOverParam.ValueMax = 525`，即翻滚后最大单发伤害 52.5；普通状态最大单发伤害为 36。
- 灭熄FF系也显式提供 `DamageLapOverParam.ValueMax = 255`，与普通状态的 25.5 相同；虽然数值没有改变，它仍属于可审计的显式翻滚后伤害。
- 溅镀枪、斯普拉机动枪、双重清洁枪和四重弹跳手枪的参数类没有显式 `DamageLapOverParam`。INKLAB 不从游戏常识或普通状态字段复制数值，因此其翻滚后伤害、击倒发数及翻滚后窗口 DPS 暂时保持待验证。
- `LapOver_RepeatFrame` 与 `LapOver_DegSwerve` 是独立的翻滚后射击间隔和扩散角。显式的 0 度扩散是有效值，不得当成空值。

## 当前计算

- `射击窗口 DPS = 单发最大伤害 × 60 ÷ 射击间隔帧`
- `100 HP 所需发数 = 向上取整(100 ÷ 单发最大伤害)`
- `理论击倒帧 = (所需发数 - 1) × 射击间隔帧`
- `满墨射击数 = 向下取整(100 ÷ 单发耗墨百分比)`
- `先翻滚一次后的射击数 = 向下取整((100 - 翻滚耗墨百分比) ÷ 单发耗墨百分比)`
- `一次翻滚等价射击耗墨 = 翻滚耗墨百分比 ÷ 单发耗墨百分比`

普通与翻滚后的 DPS 都是进入对应射击状态后的机械窗口，不包含弹道飞行和命中率。翻滚后窗口尤其不包含进入翻滚的动作、硬直、连续翻滚限制、最后一次翻滚差异、墨水回复或装备能力，因此不能称为完整翻滚循环 DPS。

## 仍待验证

- 参数文件省略 `DamageLapOverParam` 时，游戏是否按统一规则继承普通伤害；在规则来源固定前不做推断。
- `SideStepParam` 中各类 `UnrelaxFrame*` 的玩家动作含义及普通／最后一次翻滚的差异。
- 每种双枪可连续翻滚的次数与完整“翻滚—定点射击—再次翻滚”周期。
- 翻滚距离、弹道、伤害衰减与有效射程统一口径。
- 主武器省墨、行动强化等 AP 曲线对上述窗口的影响。
