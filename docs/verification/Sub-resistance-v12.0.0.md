# 减轻次要武器影响核验（Ver. 12.0.0）

## 已接入

- 重型伤害组：斯普拉炸弹、吸盘炸弹、冰壶炸弹、机器人炸弹、墨汁陷阱、鱼雷。
- 轻型伤害组：快速炸弹、碳酸炸弹。
- 标线器、洒墨器和防护墙的独立伤害倍率。
- 标线器／直击标记与墨汁陷阱的两套标记时间倍率。
- 毒雾减速影响倍率。

所有曲线使用 Leanny Ver. 12.0.0 `misc/params.json` 的三点值，并与 Sendou.ink 构建分析器中的能力键映射和伤害计算实现交叉核对。

## 公开边界

- 原始伤害大于 100 时，Sendou.ink 的公开实现不会套用伤害减轻倍率；本站明确标注为“直接致命伤害不降低”。
- 本轮展示倍率，不擅自补入尚未归一化的每个伤害段基础值。
- 本能力不影响防护墙耐久，也不把伤害、标记时间与毒雾效果合并成单一防御值。
