# 行动强化核验（Ver. 12.0.0）

## 结论

实验室与能力百科已接入行动强化的两类可复算效果：通用鱿鱼登顶蓄力时间，以及具备来源地面／跳跃扩散差值的武器空中额外扩散抑制。鱿鱼滚行的操作窗口没有在当前固定参数中形成独立数值，因此不根据能力描述反推。

## 固定来源

- 游戏版本：Splatoon 3 Ver. 12.0.0
- Leanny 参数提交：`b669d55e0eef1f1a7f18cb7468c636ed7746c189`
- 鱿鱼登顶三点值：`data/parameter/1200/misc/SplPlayer.game__GameParameterTable.json#GameParameters.spl__PlayerGearSkillParam_ActionSpecUp_Squid`
- 通用扩散抑制三点值：`data/parameter/1200/misc/params.json#ReduceJumpSwerveRate`
- 武器基础扩散与专用中点：各武器参数文件
- 交叉核对：Sendou.ink 构建分析器固定实现

记录由 `scripts/import-leanny-action-intensify.mjs` 可重复生成。174 套武器全部有记录，其中 65 套存在可计算的地面／跳跃扩散差，覆盖射击枪 32、爆破枪 17、双枪 16；17 套使用武器参数中的专用曲线中点，其余使用通用中点。

## 鱿鱼登顶

原始三点值为 `5 / 18 / 45` 帧，对应 57AP、中点与 0AP。中间 AP 使用项目共享的游戏效果强度和三点插值协议；页面与公开分析器一致，向上取整为完整帧后显示。

`3AP` 是首个可装备且会改变原始公式结果的投入，因此作为本站“最小有效值”。这是公式生效边界，不代表所有配装都需要投入行动强化。

## 跳跃射击扩散

行动强化只压缩相对地面射击额外增加的扩散：

`当前扩散 = 地面扩散 +（基础跳跃扩散 − 地面扩散）×（1 − 抑制率）`

0AP 的抑制率为 0，保留完整跳跃扩散；57AP 的抑制率为 1，最终等于地面扩散。页面不会把角度直接称为命中率，也不会为地面与跳跃扩散相同或缺少基础值的武器生成效果。

## 当前不包含

- 鱿鱼滚行输入窗口、无敌／减伤或速度变化；
- 连续射击中的扩散累积与恢复过程；
- 双枪翻滚前后不同射击状态的完整动态扩散过程；
- 实机准心动画与显示角度之间的视觉换算。

这些内容需要独立的来源字段或受控实测，不能由一次射击的角度端点直接推算。
