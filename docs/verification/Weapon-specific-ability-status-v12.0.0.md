# 武器专属能力状态核对记录（Ver. 12.0.0）

## 为什么不是一条通用 AP 曲线

“提升次要武器性能”与“提升特殊武器性能”会根据当前副武器或特殊武器改变不同类型的参数。距离、速度、持续时间、耐久、生命值和墨水消耗等单位不能合并成一个对所有武器都成立的统一百分比，也不能用其中一种武器的效果代表整个能力。

因此能力百科将这两项标为 **武器专属模型已接入**，与下列状态分开：

- **正式 AP 曲线已接入**：存在可以公开复算的通用或按武器选档曲线。
- **固定能力 · AP 曲线不适用**：只能出现在对应部位的主能力槽，按固定规则生效。
- **AP 曲线待核验**：当前尚无足够证据输出公开复算值。

## 当前覆盖

- 副武器性能：14 种副武器、17 个具名指标已经接入当前套装试算。
- 特殊武器性能：19 种特殊武器完成字段覆盖审计；其中 16 种、21 个具名指标可以试算。
- 诱饵烟花、终极着陆和鲨鱼坐骑的索引语义仍保持待核验，不从索引位置猜测参数名称。

## 产品边界

百科不为武器专属模型提供统一的“最小有效 AP”或百分比柱状图。玩家进入实验室后，页面读取当前套装身份、实际 AP 和对应指标单位；某个特殊武器仍待解释，不会使其他已经完成的专属模型整体回退成“未开发”。

自动测试保证 `subp` 与 `spu` 只进入武器专属状态、没有伪造的统一计算函数，并继续与未知能力的真正待核验状态分离。
