# 提升次要武器性能核验（Ver. 12.0.0）

## 覆盖结果

- 14 种对战副武器全部建立独立记录，共 18 个可复算指标。
- 常规投掷类读取 `SpawnSpeedZSpecUp`，但页面只展示源参数，不擅自把初速度换算成固定落点距离。
- 洒墨器分别展示高频阶段持续时间和中频阶段结束时间。
- 定点侦测器与墨汁陷阱展示标记时间；墨汁陷阱另展示感应半径。
- 斯普拉防护墙按公开分析器的 HP 比例换算耐久。
- 跳跃信标采用 Leanny 的 `SubSpecUpParam` 与公开分析器同一公式，展示跳向信标时获得的超级跳跃缩短等效 AP。

## 边界

- 不把不同副武器合成一条“通用副武增强百分比”。
- 不改变源数据没有列为能力曲线的伤害、爆炸范围或索敌行为。
- 百科继续把该能力标记为武器相关；实验室根据当前套装副武器给出完整数值。
