# 特殊武器增加量与减少量核验（Ver. 12.0.0）

## 结论

实验室已接入特殊武器增加量和特殊武器减少量的正式曲线。增加量读取当前武器套装的实际特殊武器必要点数；减少量分别展示标准被击倒、自身装备复活惩罚，以及被装备复活惩罚的对手击倒三种边界。

## 固定来源

- 游戏版本：Splatoon 3 Ver. 12.0.0
- Leanny 参数提交：`b669d55e0eef1f1a7f18cb7468c636ed7746c189`
- 能力三点值：`data/parameter/1200/misc/params.json`
- 174 套武器必要点数：`data/mush/1200/WeaponInfoMain.json`
- 交叉核对：Sendou.ink 构建分析器固定实现

套装必要点数由 `scripts/import-leanny-special-gauge.mjs` 可重复生成，当前分布为 160p ×1、170p ×9、180p ×25、190p ×61、200p ×47、210p ×27、220p ×4。

## 特殊武器增加量

倍率三点值为 `1.30 / 1.15 / 1.00`。实验室按 `向上取整（基础必要点数 ÷ 当前倍率）` 输出完整点数；能力百科使用 200p 套装作为统一展示基准。该能力降低有效必要点数，不改变单次涂墨行为本身产生的点数。

## 特殊武器减少量

被击倒后的特殊武器槽损失从 0AP 的 50% 降至 57AP 的 0%。自身装备复活惩罚时额外损失 22.5 个百分点；被装备复活惩罚的对手击倒时额外损失 15 个百分点。页面将这些边界分开，不假设对手始终装备复活惩罚。

## 当前不包含

- 最初冲刺、最后冲刺等条件能力对实际配装 AP 的临时换算；
- 逆境强化、能量站或模式规则产生的特殊武器槽变化；
- 特殊武器发动中被击倒时的武器专用处理。
