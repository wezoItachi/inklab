# 固定主能力配装联动核对记录（Ver. 12.0.0）

## 范围

头部、服装和鞋子限定能力只能出现在对应部位的主能力槽，不是可以按 0–57AP 重复堆叠的通用能力。实验室不会为它们生成虚构 AP 曲线。

当前仅有三项固定主能力能够安全复用已经核对的数值模型，并与玩家当前配装建立联动：

- **鱿鱼忍者**：先读取当前“提升鱿鱼冲刺速度”AP 和主武器重量级，再应用固定 `0.9` 倍游速修正。墨水飞沫可见性仍只作为触发规则说明。
- **隐身跳跃**：读取当前“缩短超级跳跃时间”AP，分别显示标准完整跳跃时间与距离相关的最大额外 `60` 帧。最大值不是每次跳跃固定增加的时间。
- **提升复活惩罚**：读取当前“缩短复活时间”与“降低特殊武器减少量”AP，显示自身承担的复活／特殊武器槽代价；对手侧仅显示无相关 AP 的参考边界，不猜测对手装备、能量站状态或其他条件。

## 未量化能力

最初冲刺、最后冲刺、逆境强化、回归、复仇、热力墨汁、追加装备能力增倍、提升对物体攻击力和受身术等固定主能力继续使用规则说明卡。只有当来源基础值、触发条件和计算模型都能被独立复核后，才会增加数值联动。

## 实现与回归

- 数值入口集中在 `lib/fixed-ability-analysis.ts`，明确登记为 `ninja`、`stealth`、`rp` 三项。
- 页面卡片读取完整 57AP 配装中相关通用能力的实际投入，但不会修改配装或把固定能力折算成 AP。
- 自动测试覆盖鱿鱼忍者乘数、隐身跳跃最大距离边界、复活惩罚的自身／对手分层，以及可量化固定能力白名单。
