# 提升特殊武器性能覆盖审计（Ver. 12.0.0）

## 当前结论

- 19 种特殊武器均已进入覆盖矩阵。
- 19 种均拥有名称和语义可追溯的字段，共 32 个已接入页面的指标。
- Ver. 12.0.0 参数已为诱饵烟花、终极着陆和鲨鱼坐骑补出 `SpecUpType`；其中旧数据仍省略名称的重复项，通过同一参数文件中的具名同值项以及公开分析器的 `PaintRadius` 默认规则完成交叉核对，不再依赖索引位置猜测。

## 下一步接入原则

1. 持续时间、耐久、半径、移动速度和耗墨等具名字段可按当前特殊武器分别复算。
2. 初速度只显示源参数，不伪装成固定投掷距离。
3. `SpecialTotalFrame`、`SpecialDurationFrame`、`RainyFrame`、`LaserFrame` 和 `PowerUpFrame` 保留各自语义，不合并为一个通用“持续时间”。
4. `DistanceDamageDistanceRate` 只按伤害衰减距离倍率展示，不写成伤害倍率；`PaintRadius` 等内部单位也不换算成训练场距离。

来源固定为 Leanny Ver. 12.0.0 参数快照；Sendou.ink 公开分析器已有的字段与换算规则仅用于实现交叉核对。

## 页面接入

- 19 种特殊武器现已按当前套装进入实验室 AP 试算。
- 范围、半径和初速度在没有训练场换算依据时明确标为“内部单位”。
- 触手喷射的动作耗墨和每秒耗墨按其 150% 专用墨水槽换算。
- 诱饵烟花接入 4 项、终极着陆接入 2 项、鲨鱼坐骑接入 5 项具名指标；页面继续只陈述字段语义，不把范围增长直接写成实战击倒能力。
