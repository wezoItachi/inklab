# Ver. 12.0.0 数据迁移记录

## 固定来源

- Nintendo 于 2026-11-18 发布 Splatoon 3 Ver. 12.0.0 更新公告：<https://support.nintendo.com/jp/switch/software_support/av5ja/1200.html>
- INKLAB 本轮导入固定到 `Leanny/splat3` 提交 `b669d55e0eef1f1a7f18cb7468c636ed7746c189`：<https://github.com/Leanny/splat3/commit/b669d55e0eef1f1a7f18cb7468c636ed7746c189>
- 数据使用继续遵循上游维护者要求：**Data provided by Lean**。

## 已完成

- 当前目录、套装关系和参数运行时从 Ver. 11.3.0 切换到 Ver. 12.0.0。
- 174 把对战主武器、14 个副武器、19 个特殊武器和 174 组套装关系数量不变。
- 71 把鲑鱼跑武器重新固定到 `data/parameter/1200`；现有自由目标生命值沿用其独立社区来源，并明确标注为从 11.3.0 复核结果承接。
- 重新生成字段缺口、适用性、来源和验证队列；当前共有 2417 个规范化字段，其中 1968 个已核对、117 个不适用、332 个待验证。
- 接入现有模型可以准确表达的 12.0.0 数值变化，包括窄域标记枪、广域标记枪、喷射清洁枪、回旋泼桶、爆炸泼桶等武器的伤害、耗墨或动作字段变化。
- 新增射击枪墨滴涂墨半径、爆破枪玩家移动对弹丸纵向速度影响、滚筒横挥回墨锁，以及弓最低／一段／满蓄力涂墨半径字段。

## 保留历史

`database/*.v11.3.0.json` 继续作为上一个版本的只读历史快照存在。当前界面只读取 `manifest.json` 指向的 Ver. 12.0.0 文件，不混用两个版本。

## 尚未进入产品计算

以下官方调整已记录，但现有 INKLAB 数据模型尚未把它们转换成页面结论：

- 喷墨墙的展开时间变化。
- 鲨鱼坐骑、多重导弹、触手喷射、墨雨云和能量站等特殊武器机制变化。
- 四组武器套装的特殊武器必要点数变化。

这些项目需要先确定产品用途、字段口径和界面位置。没有进入模型的内容不会被标为“已核对”，也不会从公告文字反推未公开的内部参数。

## 仍需实机或人工验证

- 各武器族射程模型与训练场换算。
- 复杂动作的完整连续周期和上游省略字段的运行时默认值。
- 普通回墨曲线在鲑鱼跑中的适用性、鱿鱼滚行空中回墨和副武墨锁规避机制。
- 副武省墨、普通对战回墨与超级跳跃时间以外的 AP 效果曲线与关键临界点。
- 12.0.0 新字段在页面中的中文标签、信息密度和手机窄屏视觉检查。

以上未验证项继续由版本化验证队列跟踪，不以官方更新公告或上游字段存在代替实机验证。
