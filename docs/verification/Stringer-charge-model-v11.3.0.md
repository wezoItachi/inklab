# 弓类三档蓄力动作模型（Ver. 11.3.0）

核对日期：2026-10-10

## 这次验证了什么

INKLAB 不再把弓类的满蓄力数据当作唯一输出口径。页面会并列计算最低蓄力、一段蓄力和满蓄力三档，并分别展示：

- 单箭直击伤害；
- 箭数已有明确来源时的单轮全中伤害；
- 蓄力帧与射击后摇组成的动作窗口；
- 动作窗口 DPS；
- 对 100 HP 目标所需轮数；
- 每档耗墨与满墨可发射轮数。

伤害、蓄力帧、耗墨、后摇、爆炸伤害及爆炸等待帧来自固定的 Leanny Ver. 11.3.0 参数快照。三发猎鱼弓的三向发射和邦普V的一次五发来自 Nintendo Splatoon Base 的公开武器说明。

## 暂不推导的内容

LACT 系参数文件没有显式箭数，当前找到的 Nintendo 说明也没有直接写出具体数字，因此其 `projectileCount` 保持“待验证”。页面仍可展示每箭伤害、蓄力帧和耗墨，但不会计算整轮伤害、整轮 DPS 或 100 HP 所需轮数。

## 公式与边界

- `单轮全中伤害 = 单箭直击伤害 × 每次发射箭数`
- `动作窗口帧 = 蓄力帧 + 射击后摇帧`
- `动作窗口 DPS = 单轮全中伤害 × 60 ÷ 动作窗口帧`
- `100 HP 所需轮数 = 向上取整(100 ÷ 单轮全中伤害)`
- `满墨轮数 = 向下取整(100 ÷ 单轮耗墨百分比)`

这是机械动作窗口对照，不是实战持续 DPS。它假设全部箭矢直击同一个目标，未计入瞄准、弹道飞行、横竖散射、爆炸命中、伤害衰减、墨水回复、装备能力、最后一轮后的取消动作或地形影响。爆炸数据单独展示，不与直击伤害相加。

页面所说的“动作窗口 DPS 最高”和“100 HP 动作预算最短”只是同一把武器三档动作的数学比较，不构成推荐打法。后续必须结合命中形态和实机验证，才能转化为攻略结论。
