## 本批结果

`scripts/import-leanny-salmon-parameters.mjs` 为 63 把常规打工武器底盘和 8 把熊先生印章武器生成 `database/salmon-weapon-parameters.v11.3.0.json`。本轮共有 71 条武器记录、674 个来源可追溯参数，其中 235 个来自常规武器 `_Coop` 显式覆盖，77 个来自熊武文件显式字段，其余 362 个由上游声明的普通武器父类继承。

所有读取文件的 SHA-256、固定提交和输出计数记录在 `database/salmon-parameter-source-report.v11.3.0.json`。N-ZAP85 是唯一在该固定提交中没有专用 `_Coop` 文件的常规底盘，因此只保留其已核验普通基础字段，并明确记录缺失覆盖文件。

## 导入规则

1. 只接受已经在 INKLAB 对战武器族模型中登记过含义、单位和规范化方式的字段。
2. 常规武器先读取已核验基础值，再按完全相同的字段路径应用 `_Coop` 显式覆盖；没有显式覆盖时记录为 `base-inherited`。
3. 熊武无父类时只接入其文件中能与已登记语义精确匹配的字段；有父类时分别记录 `parent-inherited` 与 `bear-explicit`。
4. 伤害定点值除以 10；耗墨比例乘以 100；帧数、次数、角度、内部速度和布尔值保持对应武器族既有单位。
5. 不能精确匹配路径、存在歧义或仍处于对战模型待验证状态的字段不进入正式参数列表。

## 尚未得到的结论

- 674 个参数是字段级来源记录，不代表 71 把武器都已有完整连续 DPS。
- 滚筒、画笔、弓、刮水刀、加特林等武器仍需分别解释蓄力、挥击、弹丸、贯通和重复动作周期。
- 玩家通用回墨、站立／浅墨／慢推状态、射后墨锁、三角雷墨锁与鱿鱼滚行期间回墨尚未接入。
- 敌人生命值、WAVE 出怪节奏、危险度缩放、地图、潮位和点位尚未与本表组合，因此不得输出“能否过光蝇”或通关结论。
