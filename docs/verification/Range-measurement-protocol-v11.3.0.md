# 对战主武器射程测量协议（Ver. 11.3.0）

## 目的

本协议用于关闭 `effectiveRange` 类待验证字段。它先规定“测量什么”，再规定“怎么测”，不使用游戏 UI 的射程条作为数值来源。源文件中的内部单位只用于同一语义下的对照，在换算规则获得验证前不标成训练场格数。

## 统一条件

1. 记录游戏版本、武器、武器变体、地图/训练场位置和录制帧率。
2. 默认使用平地、同高静止目标、水平视角和无主武器影响装备能力的配装。
3. 每个边界至少做 10 次重复；存在随机散布时同时保留成功次数和失败次数。
4. 保留原始录像、逐帧表和距离标定截图；摘要数字必须能回指到原始证据。
5. 记录“最后一个成功点”与“第一个失败点”，不伪造超过测量精度的小数。

## 族别口径

- **射击枪**：最远直击与开始伤害衰减两条边界；跳射、连射扩散另组测量。
- **爆破枪**：弹道终点、直击、近端爆风和远端爆风分开。
- **滚筒**：横挥和竖挥各测最高伤害/最远命中；碾压仅测接触。
- **画笔**：挥击测最高伤害/最远命中；刷地接触宽度另组。
- **蓄力枪**：先测满蓄力直击，再按固定蓄力档位补测；镜筒版单独。
- **泼桶**：主要伤害单元直击，反弹、跨障碍轨迹和爆风分开。
- **加特林**：满蓄力的衰减/最远直击；可变射击状态单独。
- **双枪**：普通与翻滚后定点射击各自测量。
- **伞**：任一弹丸最远命中与整轮达到伤害阈值两条边界；伞面另组。
- **弓**：每个蓄力档位的直击、落点分布和爆炸外边界分开。
- **刮水刀**：横斩/蓄力斩的墨刃和近身刀身共四组边界。

## 通过门槛

只有在下列条件全部满足后，页面才能把某个距离从“待测量”升为“已核对”：

- 数值有源文件字段或可复现的控制测量；
- 测量条件、命中语义和误差范围已记录；
- 内部单位换算已用至少三把不同射程的同族武器交叉验证；
- 类别专属机制没有被一个通用射程值覆盖。
